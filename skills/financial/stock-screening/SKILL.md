# 股票筛选

## 工作流程
1. 确认用户偏好：投资风格（价值/成长/白马）、行业偏好、市值范围、风险承受能力
2. 使用 `web_search` 搜索当前热门选股策略和近期被机构推荐的标的
3. 从搜索结果中提取股票代码、公司名称、入选理由
4. 交叉验证：至少对比 2 个不同来源的推荐，剔除明显矛盾的标的
5. 按投资风格分类整理推荐结果

## 搜索策略
- 主关键词：`{投资风格} 股票推荐 {年份}` + `{行业} 龙头股`
- 补充关键词：`机构调研 热门股`、`北向资金 增持`
- 注意时效性：优先搜索近 3 个月的分析报告

## 筛选维度
- 市值（大盘/中盘/小盘）
- 行业地位（龙头/细分冠军）
- 近期财务表现（营收增长、利润率）
- 机构评级和一致预期
- 技术面配合（趋势、量能）

## 输出格式
- 推荐列表（代码 + 名称 + 入选理由 + 风险提示）
- 搜索来源数量
- 需进一步基本面分析的标的
- 建议关注但未达筛选标准的候选项
