# 风险评估

## 工作流程
1. 确认评估对象（单只股票/投资组合）和风险关注维度
2. 使用 `web_search` 搜索标的的历史波动率、最大回撤、Beta 值等风控指标
3. 识别系统性风险（宏观政策、利率、汇率）和非系统性风险（公司治理、行业竞争、财务风险）
4. 设定合理的止损线和风险预算
5. 给出综合风险评级和应对预案

## 风险评估框架
- **波动率风险**：历史年化波动率，与市场和同行的对比
- **回撤风险**：历史最大回撤幅度和修复时间
- **流动性风险**：日均成交额、换手率是否充足
- **信用风险**：公司债务结构、评级、偿债能力
- **政策风险**：行业监管趋势、税收政策变化
- **黑天鹅风险**：极端事件下的压力测试

## 止损策略
- 固定比例止损：设定 8%-15% 的硬止损线
- 移动止损：随股价上涨上移止损位，保护浮盈
- 时间止损：持仓超过预期持有期仍未启动则离场
- 事件止损：基本面恶化或触发预设退出条件时立即离场

## 搜索策略
- 主关键词：`{股票名称} 风险分析`、`{股票代码} 波动率 Beta`
- 补充关键词：`{行业} 政策风险`、`A股 系统性风险`

## 输出格式
- 综合风险评分（1-10，10 为最高风险）
- 各风险维度逐一评估
- 建议止损位和仓位上限
- 极端情景压力测试结果
- 风险应对预案（分级响应）
