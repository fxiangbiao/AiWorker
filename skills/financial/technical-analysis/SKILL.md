# 技术分析

## 工作流程
1. 确认分析标的、时间周期（日线/周线/月线）和关注的技术指标
2. 使用 `web_search` 搜索该标的最新 K 线图、走势分析和指标数据
3. 依次分析趋势指标（均线、MACD）、震荡指标（KDJ、RSI）、压力支撑（布林带、前高前低）
4. 识别关键技术形态：头肩顶/底、双顶/双底、三角形整理、旗形等
5. 结合量价关系判断信号有效性，给出操作建议

## 分析框架
- **趋势判断**：多头/空头/震荡，使用多周期均线 + MACD 确认
- **超买超卖**：RSI（>70 超买，<30 超卖）、KDJ 低位金叉/高位死叉
- **支撑阻力**：布林带上中下轨、前期密集成交区
- **量价配合**：放量突破确认、缩量回调健康、放量滞涨警惕
- **背离信号**：价创新高而 MACD/RSI 未创新高 → 顶背离

## 搜索策略
- 主关键词：`{股票名称} 技术分析 {时间周期}`、`{股票代码} K线图`
- 补充关键词：`{股票名称} MACD金叉`、`{股票名称} 成交量分析`

## 输出格式
- 当前趋势判断（多头/空头/震荡）
- 各指标状态一览（均线排列、MACD、KDJ、RSI、布林带位置）
- 关键支撑位和压力位
- 买卖信号汇总 + 信号强度评级
- 短期（1-2周）走势预判
