# 基本面分析

## 工作流程
1. 确认分析标的（股票代码或名称）和分析深度（快速估值/深度分析）
2. 先用 `fs_read` 检查本地是否已有该标的的分析数据或财务报告
3. 用 `web_search` 获取最新财务数据：PE、PB、ROE、毛利率、净利率、营收增长率、净利润增长率
4. 搜索同行业可比公司的估值水平，进行横向对比
5. 结合行业景气度和公司竞争地位，给出估值判断（低估/合理/高估）

## 分析维度
- **盈利能力**：ROE、毛利率、净利率及近 3 年趋势
- **成长性**：营收增速、净利润增速、研发投入占比
- **估值水平**：PE 历史分位、PB 历史分位、PEG
- **财务健康**：资产负债率、流动比率、自由现金流
- **股东回报**：股息率、回购力度

## 搜索策略
- 主关键词：`{股票名称} 财务分析`、`{股票代码} 研报`
- 补充关键词：`{行业} 平均估值`、`{股票名称} ROE 趋势`
- 优先参考券商研报和交易所披露数据

## 输出格式
- 核心财务指标速览表
- 估值分析（历史分位 + 同行对比）
- 投资亮点和风险因素
- 综合评级（买入/持有/卖出）+ 目标价区间
- 与上次分析的对比（如有本地历史数据）
