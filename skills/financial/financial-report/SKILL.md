# 财报分析

## 工作流程
1. 确认分析标的和财报类型（年报/季报/中报）
2. 用 `web_search` 搜索该标的最新财报数据和分析解读
3. 系统分析三大报表：利润表（营收、利润、毛利率）、资产负债表（负债率、流动比率）、现金流量表（自由现金流）
4. 同比和环比分析，识别趋势变化和异常波动
5. 用 `fs_write` 保存分析报告，便于后续跟踪对比

## 分析框架
- **利润表分析**：营收同比增速、归母净利润、扣非净利润、毛利率+净利率趋势、费用率变化
- **资产负债表分析**：资产负债率、流动比率/速动比率、应收账款周转、存货周转、商誉风险
- **现金流分析**：经营性现金流/净利润比值（>1 健康）、自由现金流、筹资和投资现金流结构
- **成长质量**：营收增长是否伴随现金流改善、利润增长是否来自主业
- **异常识别**：突然的毛利率跳变、应收账款增速远超营收、大额非经常性损益

## 搜索策略
- 主关键词：`{股票名称} {年份} {季度}财报 分析`、`{股票代码} 年报 解读`
- 补充关键词：`{股票名称} 财务造假 风险`、`{股票名称} 商誉 减值`

## 输出格式
- 核心财务数据一览表（近 4 个季度 + 同比）
- 趋势分析（营收、利润、毛利率、ROE 变化图描述）
- 风险评估（财务健康度、潜在雷点）
- 与同行对比（行业百分位排名）
- 保存报告至 `data/financial-reports/{股票代码}_{日期}.json`
