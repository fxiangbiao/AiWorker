# 内容创作

## 工作流程
1. 明确内容目标：拉新、促活、转化、品牌建设，确定目标受众画像
2. 使用 `web_search` 调研热点话题、竞品内容策略、目标平台的内容偏好
3. 确定内容形式（公众号推文 / 短视频脚本 / 产品文案 / 邮件营销）与发布渠道
4. 撰写初稿：遵循平台规范，控制字数节奏，适合目标受众的阅读习惯
5. 优化传播力：打磨标题（A/B 备选 3-5 个），调整开头钩子，添加行动号召（CTA）
6. 使用 `fs_write` 输出内容到 `content-{类型}-{主题}-{日期}.md`

## 文案写作原则
- 标题公式：数字 + 痛点/好奇 + 承诺（例："3 个让你效率翻倍的…")
- FAB 法则：Feature（属性）→ Advantage（作用）→ Benefit（利益），重心放在 Benefit
- 4P 检查清单：Promise（承诺）、Picture（画面）、Proof（证明）、Push（推动行动）
- 口语化表达：读出来是否自然，避免长句和被动语态

## 不同渠道适配
- 微信公众号：标题 15 字以内，段落 3-4 行，配图建议
- 小红书：标题口语化，多用 emoji 和标签，图文结合
- 邮件营销：主题行 30 字以内，正文突出一个 CTA
- 应用商店描述：首句包含核心关键词，前 3 行抓住眼球

## 输出格式
- 内容元信息：标题、渠道、目标受众、预期阅读时长
- 正文（含排版标记建议）
- A/B 备选标题列表（3-5 个）
- SEO 关键词标签
