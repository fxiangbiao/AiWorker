# A/B 测试分析

## 工作流程
1. 使用 `fs_read` 读取实验数据文件（CSV / JSON / Markdown 表格格式）
2. 确认实验设计：实验组与对照组划分、样本量、随机化方法、运行周期
3. 计算核心指标：每组样本量、均值/比例、置信区间、p 值、效应量
4. 进行统计检验：根据指标类型选择 t 检验（连续指标）或卡方检验（比例指标），标注显著性水平 α
5. 分析次要指标与细分维度：按用户群体（新/老用户、地区、设备）拆解数据，排查辛普森悖论
6. 评估实验质量：样本量是否达标（功效检验）、是否存在分流不均、有无新奇效应
7. 使用 `fs_write` 输出分析报告到 `ab-analysis-{实验名}-{日期}.md`

## 统计要点
- 显著性不等于重要性：p < 0.05 只说明差异非偶然，需结合实际效应量判断
- 多重比较需校正：同时检验多个指标时使用 Bonferroni 或 FDR 校正
- 置信区间优于点估计：报告 95% CI 而非仅报告平均值
- 最小检测效应（MDE）：预先声明业务上足以推动决策的最小效果量

## 输出格式
- 实验信息总览：名称、假设、周期、流量分配
- 核心指标对比表（含置信区间和 p 值）
- 统计检验详情（方法、前提假设验证、效应量）
- 细分维度分析
- 🟢 可上线 / 🔴 不可上线 / 🟡 需延长实验 → 决策建议
- 附录：原始数据摘要、检验计算过程
