# 趋势预测分析

## 工作流程
1. 收集数据：行业报告、融资事件、技术博客、政策文件
2. 时间线整理：排序关键事件，识别转折点
3. 驱动力分析：技术推动 + 需求拉动 + 政策催化
4. 信号检测：弱信号（早期迹象）→ 趋势确认 → 主流采用
5. 风险评估：识别潜在障碍和不确定性

## 分析框架
- **PEST 模型**：政策(Political)、经济(Economic)、社会(Social)、技术(Technological)
- **技术成熟度**：萌芽期 → 期望膨胀期 → 泡沫低谷 → 稳步爬升 → 生产力平台
- **信号强度评估**：引用的权威来源越多，信号越强

## 输出要求
- 短/中/长期预测（1年 / 3年 / 5年）
- 每个预测标注置信度（高/中/低）
- 关键不确定性因素列表
