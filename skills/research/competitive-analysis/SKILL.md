# 竞品对比分析

## 工作流程
1. 确定对比维度（功能、性能、价格、用户体验、生态、社区、安全等）
2. 分别搜索各竞品的官方信息 + 第三方评测
3. 构建对比矩阵（行=维度，列=竞品）
4. 标注每项信息的可靠度（官方/权威媒体/个人评测）
5. 给出适用场景建议（而非绝对好坏判断）

## 对比维度模板
| 维度 | 说明 |
|------|------|
| 功能覆盖 | 核心功能完整度 + 差异化特性 |
| 性能 | 基准测试、响应速度、资源占用 |
| 易用性 | 学习曲线、文档质量、上手体验 |
| 生态 | 插件/扩展/社区活跃度 |
| 成本 | 授权/订阅/部署/维护 |
| 可靠性 | 稳定性、安全记录、灾备 |
| 技术栈 | 语言、架构、可扩展性 |

## 输出要求
- 每个维度至少引用 2 个来源
- 用 ✅/⚠️/❌ 做快速视觉判断
- 给出"场景一 → 推荐A"的务实建议
