# 代码审查

## 工作流程
1. 用 `fs_read` 读取目标文件
2. 按以下维度审查：
   - **逻辑正确性**：边界条件、错误处理、空值检查
   - **性能**：不必要的循环、重复计算、内存问题
   - **可读性**：命名、函数长度、嵌套深度
   - **安全性**：注入风险、敏感信息泄露、权限问题
   - **一致性**：风格是否与项目其余代码一致
3. 按严重程度分级输出：
   - 🔴 严重：功能 bug、安全漏洞
   - 🟡 中等：性能问题、可维护性问题
   - 🟢 建议：风格改进、最佳实践

## 输出格式
```
## 代码审查: {文件名}

### 🔴 严重问题
- [ ] 问题描述 → 建议修复方案 (行号)

### 🟡 中等问题
- [ ] ...

### 🟢 建议
- [ ] ...

### 总体评价
```
