# 数据清洗工作流

首先使用 `fs_read` 读取目标数据文件，快速浏览数据结构和内容概览，识别数据的基本形态（CSV、JSON、Excel 等格式）。重点关注列名、行数以及数据类型是否合理。

接着执行缺失值检测：逐一扫描每列的 NaN、null 或空字符串，统计缺失比例。对于缺失率低于 5% 的数值列，建议用中位数或均值填充；对于缺失率较高的列，评估是否可以直接删除该列或在后续分析中忽略。分类变量可以用众数填充或标记为"未知"类别。

然后进行异常值（outlier）检测：对数值列计算四分位距（IQR），将超出 Q1 - 1.5*IQR 和 Q3 + 1.5*IQR 范围的值标记为异常。也可使用 Z-score 方法，z > 3 视为异常。对检测到的异常值，根据业务场景决定是剔除、截断还是保留，并记录所有处理决策。

之后清理重复数据：检查是否存在完全重复的行，以及基于关键字段的重复记录。使用 `drop_duplicates` 逻辑去重，保留首次出现的记录。检查不合理的字符（如多余空格、特殊符号、编码问题），统一字符串格式，确保数据集内部分类的一致性。

处理完上述问题后，对清洗后的数据做一次完整性核查：确认行数变化合理，各列类型正确，基本统计量（均值、范围）不再出现明显异常。最后使用 `fs_write` 将清洗后的数据保存为新的干净数据文件，建议以 `_cleaned` 后缀命名，保留原始文件不动。
