# 相关性分析工作流

首先使用 `fs_read` 加载数据集，筛选出所有数值列作为相关性分析的基础变量。如果数据集中包含分类变量，先将其转换为数值编码（如 one-hot 编码或标签编码）再参与相关性计算。

第二步计算相关性矩阵：对数值变量使用 Pearson 相关系数（适用于线性关系），对非正态分布或有序分类变量使用 Spearman 或 Kendall 相关系数。通过 `terminal_exec` 运行 Python 脚本，调用 `df.corr()` 生成相关性矩阵，并绘制热力图来直观展示变量之间的关联强弱。

第三步解读相关性结果：相关系数绝对值在 0.7 以上表示强相关，0.4-0.7 表示中等相关，0.4 以下表示弱相关。注意识别多重共线性问题——如果两个自变量之间高度相关（|r| > 0.8），在后面的回归模型中可能需要剔除其一或使用正则化方法（如 Ridge 回归）。

第四步根据分析目标选择是否进行回归分析：如果是解释性分析，使用普通最小二乘法（OLS）建立线性回归模型，检查 R²、调整 R²、F 统计量的显著性。如果是预测性分析，可以尝试多元回归、逐步回归（stepwise）或使用正则化回归（Lasso / Ridge）。回归前务必检查残差的正态性、同方差性和独立性假设。

第五步输出分析结论：整理显著相关的变量对及其相关系数，标注正相关还是负相关。如果有回归模型，报告模型公式、各系数的显著性（p 值）和置信区间。将关键发现以表格形式输出到终端，并可以配合散点图和回归线进行可视化验证。
