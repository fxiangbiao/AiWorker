# 角色与数值平衡

## 工作流程
1. 用 `fs_read` 读取现有角色数据（属性表、技能配置、装备数值），建立当前数值全貌。
2. 确定平衡基准：选择一个"标准角色"作为标尺，所有其他角色与其对比。
3. 使用战斗力公式或 DPS（每秒伤害）计算模型，对比各角色在单体和群体场景下的表现。
4. 调整属性系数，确保每个角色在特定场景下有优势、在另一些场景下有短板。
5. 用 `fs_write` 输出平衡分析报告和建议调整方案。

## 属性设计原则
- **主属性**（攻击力、生命值等核心数值）决定角色基本强度，各职业应有明显侧重点。
- **次属性**（暴击率、冷却缩减等）提供差异化空间，建议用边际递减曲线防止极端堆叠。
- **反属性克制**：设计属性间的三角/五角克制关系，避免单一最优解。

## 技能平衡方法
- 建立技能强度评分公式：伤害 × 范围系数 × 命中难度 ÷ 冷却时间。
- 高伤害技能搭配长前摇或明显预警，低伤害技能可附带位移/控制补偿。
- 持续监控技能选取率和使用胜率，选取率 < 5% 的技能需重设计或加强。

## 数值曲线建议
- 线性成长（1→100）适用于轻度游戏，指数成长（1→10000）适用于长线 RPG。
- 难度曲线：初期坡度平缓（玩家学习期），中期波动上升（挑战与成就感交替），后期维持高位但不失控。

## 输出格式
```markdown
# 角色平衡分析

## 当前数据总览
- 角色 / 等级 / 主属性 / DPS / 生存评分

## 平衡问题
- 过强角色（胜率 > 60%）及原因
- 过弱角色（选取率 < 5%）及原因

## 调整方案
- 各角色属性调整建议 → 调整后预期强度

## 验证建议
- 建议的测试场景和观察指标
```
