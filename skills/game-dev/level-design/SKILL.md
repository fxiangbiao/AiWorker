# 关卡设计

## 工作流程
1. 确定关卡定位：教学关、挑战关、Boss 关还是沙盒探索关，明确关卡在整体流程中的位置。
2. 设计空间布局：使用气泡图或粗略平面图描述区域划分、连接关系和关键地标。
3. 规划玩家动线：标注主路径、可选探索区域、回头路和捷径，确保流程引导自然。
4. 用 `fs_write` 输出关卡设计文档，包含布局说明、敌人配置、机关逻辑和奖励排布。

## 节奏控制
- **引入期**：玩家进入新区域的 10-20 秒内，用视觉锚点（光源、地标、npc）吸引注意力，建立空间认知。
- **压力曲线**：交替安排高强度战斗段落和低强度探索/解谜段落，避免持续紧绷或长时间无聊。
- **高潮节点**：每个关卡至少包含一个"记忆点"——独特的场景、Boss 战或剧情事件，让玩家留下印象。

## 引导技巧
- **视线引导**：利用光线、颜色、高低差和 NPC 朝向含蓄地指示前进方向，减少 UI 箭头依赖。
- **负面空间**：用不可通行区域（悬崖、水域、废墟）自然塑造可玩边界，而非生硬的气墙。
- **可收集品布局**：将隐藏物品置于偏离主路径 1-2 步的位置，让玩家感到"发现了秘密"而不至于迷失。

## 输出格式
```markdown
# 关卡: {关卡名称}

## 概述
- 关卡类型 / 主题 / 难度 / 预计通关时长

## 空间布局
- 区域划分平面图（文字描述 + 坐标关系）

## 动线设计
- 主路径 → 分支路径 → 隐藏区域

## 敌人与机关
- 敌人类型与位置 / 机关触发逻辑 / Boss 行为模式

## 奖励排布
- 宝箱、道具、货币分布位置及获取条件
```
