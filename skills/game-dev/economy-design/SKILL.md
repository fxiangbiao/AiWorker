# 经济系统设计

## 工作流程
1. 确定经济类型：单向经济（纯 PvE）、闭环经济（玩家间交易）还是混合经济。
2. 定义货币体系：硬通货（付费货币）、软通货（游戏内获取）、特殊通货（活动/赛季限定）。
3. 设计产出与消耗：列出所有货币的获取渠道（战斗掉落、任务奖励、成就）和消耗出口（商店、升级、抽奖）。
4. 用 `fs_write` 输出经济设计文档，包含完整的流转图和数值表。

## 货币层级设计
- **硬通货**（如钻石）：产出受严格控制，消耗出口覆盖便利性道具和外观，不卖数值强度。
- **软通货**（如金币）：产出方式多样，消耗出口为日常消耗品、基础装备等，保持轻度通胀。
- **活动货币**：限时获取、限时兑换，制造稀缺感和"不换就亏"的心理驱动。

## 商店与定价
- 基础商店售卖消耗品和基础材料，价格固定，充当经济稳定器。
- 动态商店可根据玩家等级和进度调整商品池，保持购买吸引力。
- 定价公式：物品价值 = 预期获取时长（分钟）× 单位时间产出系数。

## 防通胀策略
- 追踪各货币的总产出量与总消耗量，确保消耗量 ≥ 产出量的 80%，避免货币堆积。
- 设计"回收黑洞"：装备强化失败降级、限时道具消失、赛季重置等不可逆消耗机制。
- 新版本上线时，增设高消耗出口同步存量货币，避免老玩家碾压新版本。
